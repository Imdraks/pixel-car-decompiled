# Fiches des véhicules — 0.10.0

Les 191 identifiants de carrosserie ont chacun une fiche mécanique récupérée dans
les deux versions Android. Les 239 ensembles visuels du sélecteur peuvent partager
un même identifiant mécanique. Les données ci-dessous sont celles du **jeu**,
pas des fiches constructeur. Les équations de conduite restent natives.

Les noms sont rapprochés des images du catalogue communautaire [IGCD](https://www.igcd.net/game.php?id=1000011941).
La comparaison d’image propose des candidats ; les correspondances sont revues
visuellement et les variantes incertaines restent signalées. Les deux silhouettes
101 et 154 restent à identifier. Cette identification ne valide pas une
équivalence avec le modèle réel ni avec toutes ses années et motorisations.

Le garage affiche le nom, la fiche de base et les caractéristiques de la préparation.
Dans TRANSMISSION, **TRANSMISSION D’ORIGINE** suit le modèle choisi. Une
conversion manuelle reste possible ; les anciennes sauvegardes la conservent.

Sources reproductibles : `../evidence/merged/stock-vehicles.json`,
`../evidence/merged/vehicle-identities.json` et `vehicle-identities.csv`.
Le ZIP Windows contient ces fiches et le CSV des identifications. Voir
[PHYSICS.md](PHYSICS.md) pour les conversions et les limites.
